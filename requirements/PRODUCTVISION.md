Project vision 
To build a simple and easy to use transport app that help all passengers including older people, disabled users, and those with slow internet check bus and metro time, find lost item, and report complaint easily.
Project scope
Show bus time and route information and tickets prices.
Show notices for delay warning and station facility
Let passengers complaints lost items
Include a simple help assistant to answer a common question quickly
Work smooth on cheap mobile phone with slow internet 
Provide large text and visible text 
6 key stakeholder
Bus Passengers Need to check accurate bus time and ticket costs quickly, even on weak internet.
Passengers with Visual Need screen reader support, large text
First-Time Users Need clean, simple screens with big buttons and no complicated steps
Support Staff Need an easy screen to view, track, and answer passenger complaint and lost-item reports.
Transport Officers Need simple tools to post delay alerts and route changes in real time. 
Developers Need a single, well organized GitHub repository to keep all files, code, test results, and guides in one place.
